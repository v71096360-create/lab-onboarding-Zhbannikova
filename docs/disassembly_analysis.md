# Анализ ассемблерного кода (Дизассемблирование)

## Исходный ассемблерный код (x86-64, синтаксис AT&T):

```asm
movl $0, -4(%rbp)
movl $1, -8(%rbp)
jmp .L2
.L3:
movl -8(%rbp), %eax
addl %eax, -4(%rbp)
addl $1, -8(%rbp)
.L2:
cmpl $10, -8(%rbp)
jle .L3
movl -4(%rbp), %eax
```



## Восстановленный код на Python:

```python
sum = 0
i = 1
while i <= 10:
    sum = sum + i
    i = i + 1
print(sum)
```

**Результат выполнения:** 55 (сумма чисел от 1 до 10)



## Пояснение логики работы ассемблерного фрагмента:

### 1. Инициализация переменных:
- `movl $0, -4(%rbp)` — в ячейку памяти по адресу -4(%rbp) записывается 0. Это переменная sum (аккумулятор суммы).
- `movl $1, -8(%rbp)` — в ячейку -8(%rbp) записывается 1. Это переменная i (счетчик цикла).

### 2. Безусловный переход к проверке условия:
- `jmp .L2` — переход к метке .L2, где находится проверка условия цикла. Это соответствует началу цикла while.

### 3. Тело цикла (метка .L3):
- `movl -8(%rbp), %eax` — загружаем значение счетчика i в регистр %eax.
- `addl %eax, -4(%rbp)` — прибавляем i к сумме: sum = sum + i.
- `addl $1, -8(%rbp)` — увеличиваем счетчик: i = i + 1.

### 4. Проверка условия (метка .L2):
- `cmpl $10, -8(%rbp)` — сравниваем i с числом 10.
- `jle .L3` — если i <= 10 (jump if less or equal), переходим обратно к метке .L3 (тело цикла).

### 5. Завершение:
- `movl -4(%rbp), %eax` — возвращаем итоговое значение суммы в регистр %eax (стандартное место для возвращаемого значения функции в x86-64).



## Вывод:

Ассемблерный код реализует цикл суммирования чисел от 1 до 10. На языке высокого уровня это эквивалентно циклу while i <= 10: sum += i; i += 1. Результат выполнения — число 55.
