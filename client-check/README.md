# Диагностика клиентского компьютера (Часть 2 - Анализ)

## Выбранные категории базового ПО

1. **Офисный пакет** (Office, LibreOffice, OpenOffice) — необходим для работы с документами
2. **Веб-браузер** (Chrome, Firefox, Yandex, Edge, Opera) — необходим для доступа к веб-ресурсам
3. **Программа для чтения PDF** (Acrobat, Foxit, SumatraPDF) — необходима для просмотра PDF-документов
4. **Архиватор** (7-Zip, WinRAR, WinZip) — необходим для работы с вложениями в почте

## Признаки излишнего ПО

1. **Игровые платформы**: Steam, Epic Games, GOG, Origin, Game, Gaming
2. **Торрент-клиенты**: uTorrent, BitTorrent, qBittorrent, Torrent
3. **Мессенджеры**: Discord, Telegram, WhatsApp, Viber, Skype

## Как проверялась работоспособность

1. **Проверка раздела "недостающее ПО"**: на компьютере установлен Office, поэтому раздел показывает "[OK] Офисный пакет найден". Для браузеров, PDF и архиватора выводится "[ТРЕБУЕТ ВНИМАНИЯ]" с рекомендациями.
2. **Проверка раздела "излишнее ПО"**: на компьютере найден мессенджер Viber, который попал в соответствующий раздел отчёта. Игровые платформы и торрент-клиенты не найдены.

## Ограничения решения

1. Команда `wmic product get name` выполняется медленно (несколько минут)
2. Поиск по названиям программ не всегда точен (например, "Yandex Browser" может не совпасть с поиском "Yandex")
3. Скрипт не определяет, использовалась ли программа недавно — он только сверяет с эталонным списком
4. Решение о том, является ли программа "лишней", принимает администратор, скрипт только рекомендует проверить
